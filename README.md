# HTTP-5114-ONA - Workshops in Web Development 1

This repository contains my workshop activities, assignments, and practical exercises for Workshops in Web Development 1.  
This course focuses on professional development, Git & GitHub workflows, Markdown documentation, deployment, and collaborative web development practices.

---

## Course Topics Covered

### Week 1 – Professional Setup
- Course overview
- LEGO model & voting interface activity
- Creating accounts (GitHub, Stack Overflow, Discord)
- Academic Integrity Module & assessment

### Week 2 – Git & GitHub Fundamentals
- Interview questions and coding memes
- Installing Git
- Creating repositories
- add, commit, push workflow
- Assignment: Creating repositories for each class

### Week 3 – Markdown & Documentation
- Markdown syntax
- Creating a Markdown portfolio
- Writing professional README.md files

### Week 4 – Branching
- GitHub branching
- Working with multiple branches
- Version control best practices

### Week 5 – Deployment
- Introduction to deployment
- Free deployment platforms
- Publishing projects online

### Week 6 – JavaScript UI Component
- Building an accordion using JavaScript

### Week 7 – Database & Survey
- Creating a survey using PHP and HTML
- Introductory database integration concepts
